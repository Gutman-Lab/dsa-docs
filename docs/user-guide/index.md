# User Guide

The User Guide covers using an installed DSA instance: finding images, viewing
them, and annotating them.

## Available now

- [Mouse and keyboard controls](controls.md) — the complete viewer shortcut
  reference, adapted from HistomicsUI.
- [Annotation basics](annotations.md) — the concepts behind annotation
  documents, elements, and style groups, plus the everyday workflow.
- [Annotation style groups](annotation-groups.md) — configure a shared palette
  and restrict an annotation to allowed groups.
- [Permissions and access control](permissions.md) — how users, groups, roles,
  inheritance, public folders, and annotation access fit together.
- [Troubleshooting and FAQ](../troubleshooting.md) — fixes for sign-in,
  viewing, upload, permissions, annotations, and analysis jobs.
