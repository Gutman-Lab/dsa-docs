# User Guide

The User Guide covers using an installed DSA instance: finding images, viewing
them, and annotating them.

## Available now

- [Mouse and keyboard controls](controls.md) — the complete viewer shortcut
  reference, adapted from HistomicsUI.
- [Annotation basics](annotations.md) — the concepts behind annotation
  documents, elements, and style groups.

## Planned

The following pages will be written from the HistomicsUI source and from real
use of the current release, not from memory:

- Uploading and organizing slides.
- Running analysis tasks from the interface.
- Managing users, groups, and permissions.
- Sharing collections and exporting annotations.

If you need one of these now, use the
[HistomicsUI README](https://github.com/DigitalSlideArchive/HistomicsUI) and the
[Girder documentation](https://girder.readthedocs.io/), or ask in
[GitHub Discussions](https://github.com/DigitalSlideArchive/digital_slide_archive/discussions).
