# Next steps

You have a running instance and have opened a slide. Where you go next depends
on what you want to do.

## Everyday tasks

- [Connect to a DSA server](../tutorials/connect.md) — sign in and find your
  workspace.
- [Create a collection](../tutorials/create-a-collection.md) — start a shared
  data tree.
- [Create a folder](../tutorials/create-a-folder.md) — organize a collection.
- [Copy an item](../tutorials/copy-an-item.md) — reuse a slide in another
  folder.
- [Edit metadata](../tutorials/edit-metadata.md) — record case data and other
  key/value information.

## Learn the viewer

- [Mouse and keyboard controls](../user-guide/controls.md) — pan, zoom, rotate,
  draw annotations, and use the frame selector.
- [Annotation basics](../user-guide/annotations.md) — the concepts behind
  annotation documents, elements, and style groups.

## Understand the system

- [System Overview](../system-overview.md) — single-computer and
  distributed-worker layouts.
- [What is DSA?](what-is-dsa.md) — how Girder, HistomicsUI, large_image, and
  the worker fit together.
- [Release and upgrade notes](../release-notes.md) — what changed in the
  current dated image and how to upgrade or roll back.

## Work with data and code

- Add analysis tasks by importing a Slicer CLI Web image, such as
  `dsarchive/histomicstk:latest`, from the Slicer CLI Web plugin settings in the
  Admin console.
- Use the REST API: [REST API reference](../reference/rest-api.md).
- Use the Python client: [Python client](../reference/python-client.md).
- Build interfaces with the shared React components:
  [bdsa-react-components](../reference/bdsa-react-components.md).
