# UI components (bdsa-react-components)

`bdsa-react-components` is GutmanLab's shared React component library for DSA
user interfaces. It is intended to hold reusable viewer, annotation, and data
components so that DSA front ends do not each reimplement them.

## Status

This is a placeholder page. The component reference will document only
components that exist in a pinned release, with their props, events, and a
minimal usage example. It will be added when the library's public source and
released package location are confirmed.

Until then, use the component library's source and its maintainers as the
authoritative reference. Do not treat this page as an API contract.
