# Release notes

DSA does not currently keep a maintained `CHANGELOG` file or a GitHub Releases
feed in the
[`digital_slide_archive`](https://github.com/DigitalSlideArchive/digital_slide_archive)
repository. The repository has old tags (`v1.0.0`, `v1.1.0`), but they do not
describe current releases.

Until a release-notes process exists, use these sources:

- [Commit history on `master`](https://github.com/DigitalSlideArchive/digital_slide_archive/commits/master)
- [Merged pull requests](https://github.com/DigitalSlideArchive/digital_slide_archive/pulls?q=is%3Apr+is%3Amerged)
- The [CircleCI configuration](https://github.com/DigitalSlideArchive/digital_slide_archive/blob/master/.circleci/config.yml)
  for the integration tests that run against the reference deployments
- The [HistomicsUI](https://github.com/DigitalSlideArchive/HistomicsUI) and
  [HistomicsTK](https://github.com/DigitalSlideArchive/HistomicsTK) repositories
  for changes in those components

## Planned

A short, human-written note for each documentation or deployment change will be
added here once the release process is agreed. This slice does not modify the
release flow.
