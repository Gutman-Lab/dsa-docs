# About the project

The Digital Slide Archive (DSA) is an open-source platform for storing,
managing, visualizing, and annotating large microscopy images, with a focus on
whole-slide digital pathology. It is built from Girder, large_image,
HistomicsUI, Slicer CLI Web, and HistomicsTK. See [What is DSA?](get-started/what-is-dsa.md)
for how the pieces fit together and [System overview](system-overview.md) for
the deployment model.

## History

The project builds on the Cancer Digital Slide Archive (CDSA), a public site
that hosts whole-slide images associated with The Cancer Genome Atlas (TCGA).
At more than 10,000 images and 20 terabytes, the CDSA supported TCGA Analysis
Working Group studies and other investigator-driven work. DSA packages that
experience as software that any lab can run for its own data. The
[success stories](success-stories.md) describe both efforts.
