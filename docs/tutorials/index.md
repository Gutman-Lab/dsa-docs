# Tutorials

Tutorials are task-based walkthroughs. Each one should start from a working
installation, state what you need, and end with a result you can check.

## Planned tutorials

These are the next tutorials in the documentation plan. They will be written
only after they can be run against a current release.

- Upload and organize a small slide collection.
- Set up style groups and run a multi-user annotation review.
- Run a HistomicsTK analysis on a region and open the result.
- Convert annotations to masks and back with HistomicsTK.
- Back up and restore the Girder database and assetstore.
